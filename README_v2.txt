# v2 屋根画面 修正ファイル

GitHub上の以下3ファイルを、このZIPのファイルで上書きしてください。

- index.html
- app.js
- sw.js

## 変更内容
- 勾配：2.5～6.0寸を0.5寸刻みで選択
- 「直接入力」も残す
- 勾配係数：自動計算
- 大波スレート：1.140 自動入力
- 小波スレート：1.150 自動入力
- 波型係数は必要時に手動上書き可
- 入力変更と同時にリアルタイム再計算
- 「計算面積（丸め前）」と「採用面積」を分離
- 採用面積は 1㎡切り上げ / 0.1㎡切り上げ / 丸めなし を選択可
- 材料計算へ送る面積は「採用面積」

# 菱洋 防水数量かんたん計算 v1

GitHub Pagesで運用できる静的Webアプリです。単価・原価・見積金額は扱いません。

## 主な機能
- 屋根：水平投影面積 × 勾配係数 × 波型係数 × 追加率
- 貯水槽：床・壁・天井面積、パネル枚数、内部継目、入隅、シーリング延長
- シーリング：1本あたり施工可能長さ、または容量・目地幅・目地深さから必要本数を算出
- 床・屋上・壁：平場、壁、立上り、仕切り、設備基礎、控除
- 材料：標準使用量、ロス率、必要量、菱洋通常荷姿から発注目安
- 材料・波型係数マスタ：ブラウザ上で編集
- 案件保存：localStorage + 任意でGoogle Sheets

## 初期登録している標準使用量
- ポリウレア：1.0 L/㎡
- HR480NSG-L 25mm：1.75 kg/㎡
- 20mm：1.40 kg/㎡
- 15mm：1.20 kg/㎡
- RS-アクトPUプライマー：0.25 kg/㎡
- RS-タスクPUプライマー：0.12 kg/㎡
ロス率は案件ごとに選択します。

## 菱洋通常荷姿
PG 406-9 / PG430 / PG409 / PG408 / PG411：400L / 36L
PG301 / PG809-20 / PG809-40：40L

NUKOTEやSPUの通常荷姿も初期登録済みです。

## GitHub Pages
このフォルダの中身をリポジトリ直下へアップロードし、
Settings > Pages > Deploy from a branch > main / root で公開できます。

## Google Sheets連携
1. 新規Googleスプレッドシートを作成
2. 拡張機能 > Apps Script
3. gas/Code.gs を貼り付け
4. setupSheets() を1回実行
5. Webアプリとしてデプロイ
6. 発行URLをアプリの「案件 > Google Sheets連携」へ登録

## 注意
- 大波スレート等の波型係数は製品形状で変わるため初期値を推測で入れていません。
- HR480NSG-Lは標準使用量がkg/㎡、現在の荷姿情報がLなので、密度等が未登録の状態では発注セット数を自動換算しません。
- 本アプリは概算用です。正式数量は現場、仕様書、下地、役物、立上り、配管、ドレン等を確認してください。
